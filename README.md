# Thiago Barros — Professional Portfolio

Static professional portfolio built with vanilla HTML, CSS and JavaScript.

## Structure

- `index.html` — page structure and content
- `styles.css` — visual identity, responsive layout and animations
- `script.js` — PT/EN localization, scroll animations, counters and mobile menu

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

Example with PHP:

```bash
php -S localhost:8080
```

Then visit `http://localhost:8080`.

## Before publishing

Replace the placeholder email `thiago@example.com` in `index.html` with the desired professional email, and add real LinkedIn/GitHub links if desired.
